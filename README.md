# Banking System Using OOP

## Project Overview

This project is a console-based Banking System built in Python using Object-Oriented Programming (OOP) principles. The application simulates real-world banking operations such as account creation, deposits, withdrawals, fund transfers, and savings account management.

The project demonstrates the implementation of important OOP concepts including classes, objects, inheritance, method overriding, encapsulation, and custom exception handling.
## Key Features
- Account Creation
- Balance Inquiry
- Deposit Funds
- Withdraw Funds
- Transfer Money Between Accounts
- Interest Reward Accounts
- Savings Accounts with Withdrawal Fees
- Custom Exception Handling for Insufficient Balance
## OOP Concepts Implemented
- Classes and Objects
- Inheritance
- Polymorphism
- Method Overriding
- Encapsulation
- Custom Exceptions
## Technologies Used
- Python 
- Object-Oriented Programming (OOP)
- Exception Handling
